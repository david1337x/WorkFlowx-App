# WorkflowX Task Manager

Ultra-premium futuristic To-Do List application built with Vanilla JavaScript.

## Features

- Add, edit, complete, and delete tasks
- Filter tasks (All / Active / Completed)
- Real-time task stats and progress tracking
- LocalStorage support
- Drag and drop task reordering
- Animated particle background
- Cinematic intro loader
- Premium UI animations
- Smooth sound effects
- Fully responsive design
- Works completely offline

## Keyboard Shortcuts

| Key | Action |
|------|---------|
| Enter | Add Task |
| Esc | Clear Input |
| 1 / 2 / 3 | Change Filters |
| S | Toggle Sound |
| N | Focus Input |

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Download or extract the project ZIP
2. Open `index.html`
3. Start managing tasks

No installation or internet required.
